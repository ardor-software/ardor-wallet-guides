This repository is the part of the Ardor Wallet guide set that deals with the application itself: getting it onto a machine, keeping the secret that opens it, deciding whether the software can be trusted, and moving ARDR in and out of it. Every guide here answers a question a reader actually types into a search engine, and each one opens with the answer rather than with background.

It helps four kinds of reader most: someone installing a desktop wallet for the first time, someone who has lost or mistyped a passphrase, someone deciding whether a download is genuine, and someone who needs to send ARDR to an exchange without losing it. The guides assume no prior knowledge but they do not pad the steps, so a reader who already knows the basics can skip straight to the fix.

The set is grouped the way a reader arrives. Start with the wallet covers installation, the download check, the login question and the release notes. Accounts, passphrases and recovery holds the material that matters before an account is funded. Safety and inspections is where the software itself is examined, including the licence and hardware devices. Holding, buying and sending ARDR is the money side, from the first purchase to the withdrawal to a tax report.

Every page repeats one habit, because it is the only reliable defence: take installers from the release page, compare the SHA-256 value published beside the file, and treat the passphrase as an object that exists on paper and nowhere else. A download that arrives from a chat message, an advertisement or a search result above the official one is not worth the risk, however convincing the page looks.

Use the tables below to find the question you have now. Each title links to a page that answers it and then links onward to the two related guides most likely to be needed next, so the set works as a path rather than a pile.
